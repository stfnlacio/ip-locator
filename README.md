# IP Locator

A beautiful IP Address Locator for Termux & Linux.  
Created by **Stefan Lacio**.

---

### Features
- Beautiful colored design
- Shows city, region, country, coordinates, timezone, ISP & ASN
- Works on Termux and normal Linux
- One command install
